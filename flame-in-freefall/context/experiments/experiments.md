# SoFIE
NASA ran the Solid Fuel Ignition and Extinction project (SoFIE) from July 5, 2022 until February 2025. The project consisted of five experiments which aimed to improve understanding of how flames spread and materials burn in different environments.

# ACME
ACME is a set of six investigations examining fuel efficiency and pollutant production in combustion and stands for Advanced Combustion via Microgravity Experiments.
